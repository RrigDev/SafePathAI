📚 Data & methodology — how this was built
Dataset
Indian historical crime dataset · {{ "{:,}".format(meta.records) }} incidents across {{ meta.cities }} cities (incidents with a usable time of day)
Resolution
City level × four time bands (morning, afternoon, evening, night). No street-level coordinates exist in the data.
Risk score
60% frequency (incidents vs the city's own average) + 40% severity (weighted by crime type: homicide 10 … traffic violation 1). Safety score = 100 − risk.
Machine learning
{% if ml_available %} Random Forest classifier (city, hour, weekday, month → violent or not) {% if ml_metrics and ml_metrics.roc_auc is not none %}· ROC-AUC {{ ml_metrics.roc_auc }}{% endif %} {% if ml_metrics and ml_metrics.n_train %}· trained on {{ "{:,}".format(ml_metrics.n_train) }} records{% endif %} {% else %} Not loaded on this server. {% endif %}
Places & routes
OpenStreetMap: Nominatim / Photon (geocoding), Overpass (nearest hospital, police, transit), OSRM (walking routes)
Limitations
Historical, reported crime only · city-level, not street-level · not real-time · scores compare times of day within a city, not cities with each other · not a guarantee of safety

SafePath AI is a student prototype. Risk scores are calculated from a historical crime dataset and represent city-level, time-of-day patterns — not street-level or real-time crime prediction. This tool is not a guarantee of personal safety. In an emergency, call 112.
